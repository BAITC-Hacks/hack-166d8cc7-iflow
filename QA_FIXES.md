# Исправления после независимого аудита

Дата: 23.09.2026. Исходный `TEST_AUDIT.md` и его записанные результаты оставлены без изменений: они описывают состояние до исправлений. Этот документ — проверка исправлений разработчиком, не новый независимый аудит.

## Изменения

| Дефект | Исправление |
|---|---|
| D01: выдуманные факты объяснения | LLM выбирает курс; backend формирует текст из реального gain, max_level, critical flags, требований и истории. Произвольный текст/гипотезы модели не публикуются. |
| D02: приписанная карьерная цель | При `career_goal=null` в тексте явно указано, что следующий грейд — ориентир по умолчанию. |
| D03: HR не видит отсутствие рекомендаций | Добавлены список сотрудников и состояния ready / failed / stale / not_generated / needs_clarification / no_candidates. Устаревший fingerprint не считается готовым ответом. |
| D04: скрытый критичный пробел | HR получает сотрудника, навык, требуемый и достижимый уровни. Наличие курса по другому навыку не скрывает проблему. Покрытие рассчитано для одного прохождения каждого доступного сейчас мероприятия, с соблюдением caps. |
| D05: публичный HR-вход | Удалены кнопки с публичными credentials. Startup из окружения отвергает старые demo-токены; выдаются приватные случайные credentials через `backend/provision_access.py`. |
| D06: ошибка evidence срывает допустимый выбор | Для реального доступного курса повреждённые ссылки заменяются проверенными фактами кандидата. Неизвестные/недоступные ID продолжают отклоняться. |

Дополнительно сокращён структурированный ответ OpenAI: исключена генерация длинного объяснения. При таймауте возможна одна повторная попытка, делящая исходный сетевой бюджет. Auth/quota ошибки не повторяются. Без ответа LLM курс не выдумывается.

Ключ кэша обновлён: старые объяснения не используются как актуальные. Старые предложения перед отправкой также проходят проверку fingerprint.

## Ограничения

Это private bearer access для MVP, не корпоративный SSO. Уточняющие вопросы ещё не имеют сохраняемого диалога. Browser click-through и нагрузочная проверка не выполнены. Семантическое качество выбора на всех неизвестных профилях не гарантируется; независимость initial QA не распространяется на этот follow-up.
